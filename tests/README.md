# gm-tools Test Harness (Step4/Step5)

This repository contains a Python3-based test harness for **gm-gather / gm-scatter**.

- No outer shell usage over SSH (arguments-only).
- sudo with `-n` (NOPASSWD required).
- Full type annotations and constants centralization.
- Environment variables compatible with previous shell-based runs.

See `README.md` for setup and `run_step4.sh` / `run_step5.sh` for execution.
